# moving-average-backtester
## Overview
Moving Average Backtester implemented using Excel and Python (Pandas, NumPy, Matplotlib) to analyze stock price trends and backtest trading strategies.
## Tools & Technologies
- Microsoft Excel (Financial functions, Dashboard)
- Python
- Pandas
- NumPy
- Matplotlib
## Methodology
- Imported historical stock price data
- Calculated moving averages
- Generated buy/sell signals
- Backtested strategy performance
- Visualized results with Python graphs
## Key Results
- Cumulative returns plotted
- Signal analysis for buy/sell points
- Risk vs reward metrics
